📋 ภาพรวมระบบ
ระบบนี้แปลงใบสั่งงานกระดาษ/Word แบบเดิมให้เป็นเว็บแอปพลิเคชัน โดยมีความสามารถหลัก:

สร้างใบสั่งงานรายเดือนตามสัญญา พร้อมคำนวณปริมาณงานสะสม/คงเหลืออัตโนมัติ
ลงนามดิจิทัลทั้งฝ่ายผู้ว่าจ้าง (EECO) และผู้รับจ้าง
แนบรูปภาพหน้างานประกอบใบสั่งงาน
ส่งลิงก์เฉพาะให้ผู้รับจ้างเข้าดู/เซ็นได้โดยไม่ต้องสมัครสมาชิก
Export PDF ตามรูปแบบฟอร์มต้นฉบับ EECO
แจ้งเตือนอัตโนมัติผ่าน Email และ LINE Messaging API
